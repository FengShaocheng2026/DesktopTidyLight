# 当前架构

版本：0.1.5。C# / WinForms / .NET Framework 4.8，Windows x64。

## 图标与桌面

`GroupFrame` 是附着到 Explorer 桌面层的窗口；`IconCanvas` 绘制图标、名称、选中状态和滚动条。透明背景使用单独的背景层，图标保持不透明。分组移动不逐个移动原始图标。

`DesktopShell` 集中读取 Shell 项目、稳定文件身份和坐标。运行分组时通过 Windows 的 [FWF_NOICONS](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/ne-shobjidl_core-folderflags) 关闭原生图标绘制，分组成员不再移到屏幕外。未分组项目由每个显示器上的透明桌面画布按原坐标绘制，排在分组下方；画布只接收图标单元格和框选轮廓区域的输入，保留空白桌面的系统菜单。支持打开、Ctrl/Shift 多选、框选、拖入分组、移回桌面、F5 和 Shell 项目右键菜单。整理操作不移动、复制或删除用户文件；系统菜单中的文件操作由用户自行选择。

`LayoutController` / `UnifiedLayout` 负责成员关系和事务：先保存恢复记录，再改变原生图标显示状态或显式拖回桌面时的位置，随后读回验证并提交。`OriginalIconsVisible` 保留启动前的显示设置，`PendingIconsVisible` 支持失败回退；正常退出、删除最后一个分组和 `--restore` 都恢复原设置。也支持从旧版异常退出后的屏幕外位置迁移。失败时回退；成功回退的暂时定位失败可延后重试。保存失败或回退失败停止自动操作，保留恢复记录和已有画布。

旧的原生图标排列分支仍服务于历史布局兼容与回归检查，不用于新版分组移动。

## 后台工作与资源

- `DesktopScan` 复用一个 STA 后台线程，空闲时约每 3 秒枚举桌面。`DesktopEvents` 收到 Explorer 桌面变化通知，以及后台扫描完成时，都会合并唤醒前台检查，不再等下一次 80 毫秒定时器。扫描期间桌面再次变化时，触发重新读取与身份核对，不反复丢弃结果；用户修改了分组记录时仍丢弃旧快照。只传递普通数据，每次读取在同一线程创建和释放 COM 对象。
- 桌面列表暂时缺少某个成员，但其原路径上的文件身份仍匹配时，保留原布局并稍后重试，避免刷新重建被误判为删除。图标区域独立使用普通箭头，不继承分组标题和边框的移动、缩放指针。
- 前台窗口切换和 Explorer 重排会合并触发层级检查，80 毫秒定时检查仍作兜底。层级维护不受图标同步忙碌或拖动状态阻断；只排除桌面宿主窗口，不排除整个 Explorer 进程。分组先附着再显示，自动抬高请求改为重新定位到桌面层级。
- 图标加载由各画布的有界 STA 队列负责，最多 128 个待处理项目。离开可见区域的排队任务会取消，空闲加载线程退出。
- 单元格位图只缓存可见区域，图标缓存覆盖附近页面；刷新、缩放变化和关闭窗口释放对应资源。
- 透明度滑块合并快速输入，数值不变时不保存，松开鼠标提交最终值。
- 不通过强制垃圾回收或裁剪工作集制造内存下降。

## 显示器与持久化

`DisplayLayout` 保存显示器身份、工作区、缩放和首选位置。临时移除显示器时将分组约束到可见区域，保留原显示器记录。`TidyContext` 同时监听环境变化、检查桌面窗口是否重建并比较屏幕工作区。

配置位于 `%LOCALAPPDATA%\DesktopTidyLight\layout.json`，使用原子替换和内部备份。`last-notice.txt` 仅记录最近一次通知，不持续增长。不提供用户手动备份导入或撤销界面。

## 验证入口

`tests/run-checks.ps1` 构建主程序与测试程序，默认执行不修改真实桌面的回归检查。`MvpChecks.exe --desktop-diagnostics` 只读检查原生绘制状态、项目和分组；输出可能含个人文件名，不应提交。

默认检查包含隐藏测试窗口的真实置顶请求、显示前定位、桌面事件筛选、显示状态恢复及画布输入区域；不显示测试窗口、不切换前台应用。`--native-visibility` 在主程序停止时短暂隐藏原生图标并执行三次 Shell 刷新，随后恢复原设置；`--managed-refresh-check` 在新版运行时检查三次刷新是否仍保持关闭绘制。它们不操作鼠标键盘，也不能替代实际拖放、系统菜单和特定全屏应用的交互验收。异常终止后请重新启动或运行 `--restore`；显示器热插拔、Explorer 重启和系统升级仍需进一步实机验证。

`--performance` 使用临时文件和屏幕外测试窗口；`--unified-render` 验证透明、窗口层级和四种外观。`--unified-shell` 会创建自己的临时桌面项目，应在受控实机验收时单独使用。空闲资源采样运行 `scripts/Measure-Idle.ps1`，输出位于忽略的 `build/review/`。
