# 配置路径与恢复

程序配置保存在 `%LOCALAPPDATA%\DesktopTidyLight\layout.json`。从打包应用内的开发终端启动程序时，Windows 可能把文件和注册表访问重定向到该应用的隔离目录。这样，开发终端与正常桌面启动的程序会读到两份同名配置，表现为重启后分组或设置“消失”。

实机验收应从 Windows 桌面快捷方式启动，并通过该实例的托盘菜单退出。若设置未恢复，先分别备份两边配置，再确认程序实际打开的文件路径；仅比较环境变量或路径字符串不够。可用文件句柄的 `GetFinalPathNameByHandle` 核对最终路径。目标配置已有分组时，不要直接覆盖。

布局文件使用原子替换并保留内部备份。恢复前应检查主文件、备份和未完成事务；不要把个人布局、诊断输出或恢复备份提交到仓库。关于 Windows 重定向机制，可参阅[微软文档](https://learn.microsoft.com/en-us/windows/msix/desktop/desktop-to-uwp-behind-the-scenes)。
