# 0.1.2 验证范围

适用环境：Windows 11 x64、.NET Framework 4.8。该版本提供桌面分组、批量拖拽与排序、外观设置、自动保存、退出还原及重启恢复。显示器位置按身份记录；图标异步加载，并可手动刷新。

封版时主程序与检查程序构建成功，70 项默认回归检查通过。四种外观、透明背景和桌面窗口层级通过检查；本机 4 个分组、41 个成员在重启后恢复正常，双屏诊断未发现可见的原始成员或未完成事务。这些是当时的测试结果，不代表后续代码或所有设备配置均已通过。

仍需验证长时间运行、物理显示器热插拔、远程桌面，以及更多 Windows 更新和 Explorer 重启组合。Shell 偶尔会返回通用图标，可从分组菜单手动刷新。

性能检查的方法、结果和限制见[性能检查](performance-2026-10-12.md)。
