# MVP 0.1.2 封版记录

日期：2026-10-12。Windows 11 x64 / .NET Framework 4.8。

## 本版范围

- 统一绘制图标、批量拖入与拖出、组内排序、分组重叠、边界限制、吸附和锁定。
- 四种外观、透明度、自动隐藏标题、统一设置；托盘仅设置与退出。
- 自动保存、退出还原普通桌面、重启恢复分组，显示器身份与首选位置记录。
- Shell 图标异步加载、有限缓存、失败自动重试；保留手动刷新图标。
- 显示环境变化后重新隐藏原始成员；定位失败成功回退时等待 10 秒重试。保存或回退失败仍安全暂停。
- 封版优化：桌面扫描复用 STA 线程，透明度不变时不重复保存，空图标队列跳过无意义临时分配。

## 验证

- 主程序和检查程序构建成功，0 警告、0 错误；70 项默认回归检查通过。
- 四种风格渲染、透明背景、原生窗口层级检查通过；石墨风格合成预览已人工检查。
- 性能与资源采样见 [性能记录](performance-2026-10-12.md)，不将控件耗时等同于屏幕帧率。
- 本机 4 个分组、41 个成员重启正常；双屏诊断无可见原始成员、无未完成事务。观察到双屏从 4K 变为 1080p 后恢复正常；本轮未主动操作系统分辨率或物理插拔。

## 仓库整理

保留当前源码、测试、图标源文件与成品 ICO、打包脚本、资源采样脚本，以及当前使用/架构/验证说明。过时原型需求、重复方案、UI 概念页面、旧截图、调研检出、旧构建和中间文件移至仓库外的本机开发归档。批量删除被自动审批拒绝，因此使用保留式归档，不宣称释放了相应磁盘空间。个人布局和注册表恢复资料不纳入 Git。

发布包仅包含 EXE、配置、使用说明；`dist/`、`build/`、`bin/`、`obj/` 均忽略。版本统一来自主项目文件，可用 `packaging/Package.ps1 -Version x.y.z` 显式覆盖。

## 尚未覆盖

长时间运行、物理热插拔、远程桌面、多种 Windows 更新与 Explorer 重启组合仍需后续验收。Shell 返回成功但内容为通用图标时不一定能自动识别，保留“刷新图标”。MVP 封版表示本轮功能冻结，不表示所有兼容性场景均已验证。
