# 交互性能检查（2026-10-12）

## MVP 0.1.2 封版复测

- 默认 70 项检查通过；补充透明度数值不变时不保存，以及连续 50 次扫描复用同一 STA 线程的验证。
- 桌面扫描改为复用一个后台线程，避免周期性创建线程。读取仍创建新 Shell 会话并及时释放，不跨线程传递 COM 对象。
- 本机 4 个分组、41 个成员，约 47 秒采样：工作集 82.2→82.6 MiB，私有内存 42.3→42.2 MiB，句柄 559→538，GDI 106 不变，USER 70→62；22 逻辑处理器下整机平均 CPU 约 0.20%。采样期间存在显示环境变化，不是严格空闲对照，不能用于宣称固定降幅或长期无泄漏。
- 同次测试工具结果（中位数 / P95）：缓存绘制 4.92 / 11.63 ms，滚动 14.15 / 17.91 ms，缩放 6.42 / 8.57 ms，透明分组移动 1.99 / 3.45 ms；后台扫描派发 0.01 / 0.88 ms。首次可见区域 70.28 ms，真实图标后台补齐另需约 1007 ms。
- 当前未发现需要封版前继续扩大改动的缓存增长问题。后续优先做数小时运行、频繁显示器切换与慢 Shell 扩展压力测试；这些不属于已完成验证。

以下为之前的优化对照记录，测试环境与本轮不同，不直接横向比较。

## 方法与范围

运行 `MvpChecks.exe --performance`。1000 个临时文本文件作为成员；只绘制可见项目，120 次向下/向上滚动、120 次缩放、200 次透明分组原生窗口移动。窗口放在屏幕外，不移动用户文件或现有分组。读取当前桌面用于只读枚举测量；配置保存写入临时目录。显示器切换使用模拟 1080p/4K、96/192 DPI 和负坐标，不改变系统显示器配置。

数值为单轮本机控件/调用耗时，不是屏幕帧率。首次绘制只有一个样本，包含首次初始化。优化后绘制使用占位图，真实图标后台补齐；新增事件处理，因此前后数据并非严格实验室对照。

## 改动

- Shell 图标和快捷方式名称读取移到 STA 后台线程（兼容 Windows Shell），绘制/悬浮提示/拖拽预览不再同步读取文件图标。
- 每个画布最多 128 个待处理项目；滚动时取消已离开可见区域的排队任务。过期结果、刷新前结果和已关闭窗口的结果会释放。
- 位图只缓存可见单元格，图标缓存覆盖附近页面；不随 1000 个成员全部增长。空闲工作线程自动退出。
- 后台同步没有状态变化时不再刷新全部分组；延迟刷新避开鼠标按下和图标拖动。

## 验证和限制

67 项回归检查通过。补充慢加载、后台线程类型、队列上限、刷新后旧结果丢弃测试；原生窗口层级、透明背景、四套风格渲染检查通过。实际运行截图确认 Fork 等图标和名称正常。4 个分组、40 个成员正常恢复，无待恢复事务。

短时资源采样：优化前 20.7 秒，工作集 94.9 MiB、私有内存 41.0 MiB；优化后 30.8 秒，工作集 94.4→94.5 MiB、私有内存 41.1 MiB、GDI 104、USER 60 保持不变。整机平均 CPU 约 0.11%→0.12%，无可声称的 CPU 降幅。采样期间有截图，不是严格空闲对照，也不能排除长时间泄漏。

仍有优化空间：周期性桌面枚举仍同步执行，实测约 37～49 毫秒；首次界面初始化仍有约 148 毫秒开销；单个 Shell 扩展卡住时，同一分组后续图标需要等待该后台调用返回，但界面和退出不等待。下一步应围绕桌面变化通知及安全的异步快照处理验证，不破坏文件身份核对和恢复事务。实际混合 DPI 跨屏拖动、拔插和长时间运行仍需人工验证。


## 第二轮：后台桌面检查

已将上文尚未解决的周期性桌面枚举移到单个 STA 后台任务。只传递项目、位置、身份和桌面环境等普通数据，COM 对象在工作线程创建、释放。界面仅判定是否有变化；无变化时不打开 Shell、不复制布局、不写文件。

检测到变化仍重新读取当前桌面，继续使用原来的文件身份检查和持久恢复事务；后台结果不直接执行移动。扫描期间用户修改了布局时，旧结果丢弃并重新扫描。任务最多一个，错误返回界面统一处理，关闭应用不等待慢扫描。

本机 20 次实际后台扫描：界面派发中位数 **0.50 ms**、P95 **0.83 ms**；测试消息循环最大间隔 **16.24 ms**（包含调度和 Sleep，不是帧率或输入延迟保证）。同期同步只读枚举中位数 23.37 ms、P95 40.15 ms，仍需这些后台工作时间。

同时去掉拖拽接受状态不变时的重复重绘。71 项检查通过，包括慢扫描、线程隔离、重复任务拦截、关闭不等待、异常后重试、位置/重命名/替换识别，以及重复拖拽反馈不重绘。首次加载和渲染测量会受到系统缓存及调度影响，不将本轮其他指标的波动全部归为优化收益。

剩余边界：用户明确改变成员、恢复布局、Explorer 重启或显示器变化时，安全事务仍可能短暂占用界面；正在执行的第三方 Shell 调用不能强制安全终止。不能承诺所有硬件和扩展下零卡顿，也没有用跳过身份检查或延迟保存换取指标。


新版启动阶段 30.8 秒平均整机 CPU 约 0.47%，包含首次图标加载；稳定运行后另测 30.8 秒，整机 CPU 约 **0.067%**、工作集 **95.0→95.1 MiB**、私有内存 **40.64 MiB** 不变、GDI **104** 和 USER **60** 不变。句柄 618→518，未呈现增长趋势。此为短时观察，不能替代长时间泄漏测试。观察期配置文件修改时间保持在启动时，4 个分组、40 个成员、无待恢复事务。
