# 性能检查

以下为 2026-10-12 在一台 Windows 11 机器上的短时测量，适用于当时的 0.1.2 代码，不代表所有设备的表现，也不能证明长期无内存泄漏。

## 方法

`MvpChecks.exe --performance` 使用 1000 个临时文本文件和屏幕外测试窗口，测量可见区域绘制、滚动、缩放和窗口移动。它不会移动用户桌面文件或现有分组。另用 `scripts/Measure-Idle.ps1` 对实际桌面实例进行资源采样。控件耗时不是屏幕帧率。

## 结果

| 项目 | 中位数 / P95 |
| --- | --- |
| 已缓存绘制 | 4.92 / 11.63 ms |
| 滚动 | 14.15 / 17.91 ms |
| 缩放 | 6.42 / 8.57 ms |
| 透明分组移动 | 1.99 / 3.45 ms |
| 后台扫描派发 | 0.01 / 0.88 ms |

首次可见区域绘制为 70.28 ms，真实图标后台补齐约需 1007 ms，均为单轮观察。一次约 47 秒的实际桌面采样中，工作集为 82.2→82.6 MiB，私有内存为 42.3→42.2 MiB，GDI 对象数保持 106。采样期间显示环境发生变化，因此不能据此推断稳定空闲占用或固定性能收益。

后台桌面扫描复用一个 STA 线程。Shell 调用仍在后台消耗时间，第三方 Shell 扩展卡住时不能安全强制终止。长时间运行、频繁显示器切换和慢 Shell 扩展仍需测试。
