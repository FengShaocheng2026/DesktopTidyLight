# 桌面整理软件竞品调研

调研日期：2026-10-11。以下是公开产品页面和项目说明中的**已声明功能**，不是安装后的实测结果；“轻量”宣传也不等于已经验证资源占用。

| 产品 | 核心做法 | 已声明的扩展功能 | 对本项目的启发 |
| --- | --- | --- | --- |
| [Stardock Fences 6](https://www.stardock.com/products/fences/index.cshtml) | 在桌面上用区域组织图标，支持手动放入和规则分类 | 文件夹映射、标签页、Peek、外观自定义、快照等 | 分组和日常访问是核心；丰富功能不能替代简单可靠的基础体验 |
| [腾讯桌面整理](https://pc.qq.com/detail/5/detail_23125.html) | 桌面“格子”和一键分类，可自定义布局 | 云文件、AI 解析、文件夹映射；[产品页](https://guanjia.qq.com/product/zmzl/)还列出全盘搜索、壁纸 | 有清晰的中文用户场景，但功能范围已经远超单纯分组；官方软件中心当前标注安装包约 202.78 MB，此数字是包大小，不代表运行内存 |
| [Portals](https://portals-app.com/) | 在桌面直接显示指定文件夹的内容 | 多标签、布局、配置档案和大量外观选项 | “展示文件夹”与“分组现有桌面图标”是两种需求，不能混为一谈 |
| [Pickets](https://github.com/Creeptones/Pickets) | 把桌面文件、文件夹和快捷方式收进可移动、可折叠的组 | 托盘、快捷键等 | 明确承诺不移动/删除原文件，退出时恢复图标，并提供故障恢复命令；恢复能力值得作为第一版要求 |
| [PecoFence](https://github.com/DayuanJiang/PecoFence) | 桌面分组框，兼有规则和文件夹视图 | 标签、快照、设置导入导出、外观主题等 | 开源产品也可做得很完整；第一版应刻意收窄范围。其项目说明称规则分类不移动原文件，退出时恢复图标 |

## 初步判断

1. 本项目要解决的是“**把已经在 Windows 桌面上的图标分成几组并继续正常使用**”，不是代替文件管理器。
2. 用户对轻量的感受可能来自安装、启动、常驻、操作复杂度和额外功能。只有安装包大小有公开可比数字；其余应在原型阶段实测，不能现在声称比竞品更省资源。
3. “不移动真实文件”和“能恢复普通桌面”比自动分类更适合先做：这两项直接决定试用成本和数据风险。
4. 竞品是否与特定 Windows 版本、缩放比例、多显示器、OneDrive 桌面重定向兼容，不能只凭产品页推断。本项目需要单独验证。

## 仍需验证

- 在真实 Windows 桌面上试用代表性竞品，记录图标拖放、双击、右键菜单、文件改名/删除、退出恢复的实际行为。
- 用真实机器测量启动时间、空闲内存、空闲 CPU 和分组操作响应；此时再设性能目标。
- 验证目标 Windows 11 桌面能否在不移动文件的前提下稳定地将原生图标排入分组区域、保持拖放和右键操作，并在崩溃后恢复。此项决定具体实现方案。
