# 桌面 Shell 探测工具（默认只读）

用途：确认 Windows 11 的 Explorer 桌面视图能否通过公开 Shell 接口枚举图标、读取位置和定位图标。默认运行、`--selected` 与 `--list` 都是只读模式，不会移动图标、修改文件、写入设置或创建窗口。

在装有 Visual Studio C++ Build Tools 和 Windows SDK 的 PowerShell 中运行：

```powershell
.\tools\DesktopProbe\build.ps1
.\build\DesktopProbe\DesktopProbe.exe
```

默认只输出数量、位置读取错误数以及“自动排列”状态，不输出桌面文件名。`--selected` 只读当前已选中的图标数量和位置读取结果，不改变选择；`--list` 会输出全部图标名称和位置，仅在需要时使用。

显式运行 `--test-position` 时，工具会在当前用户桌面创建一个唯一命名的临时文本文件，只尝试移动它的图标 24 像素，再请求恢复原位置并删除测试文件。`--test-position-manual` 还会临时关闭“自动排列”和“对齐到网格”，完成后恢复原设置。这两种模式都不会调用删除其他桌面项目的接口，但可能改变桌面图标排列；请先保存正在进行的工作。工具不弹窗口，也不主动抢焦点。测试中断时可能留下以 `DesktopTidyLight-P1-` 开头的临时文本文件，可核对后手动删除。

定位模式返回码：`0` 表示实际移到请求位置并回到原位；`2` 表示接口返回成功但图标没有到请求位置；`3` 表示未回到原位；`1` 表示接口或文件操作失败。请同时阅读坐标和设置状态输出。

定位测试不代表分组框交互、多选拖放、Win+D 或异常恢复已经通过。
